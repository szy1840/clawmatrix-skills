# clawmatrix-skills

OpenClaw skill package for **ClawMatrix** Reddit automation (post, comment, upvote) and task reporting. Install via [`@clawmatrix/cli`](https://www.npmjs.com/package/@clawmatrix/cli) (`onboard`) or [`@clawmatrix/install`](https://www.npmjs.com/package/@clawmatrix/install); the repo is cloned to `~/.openclaw/skills/clawmatrix`.

See `SKILL.md` for the full skill definition and workflow.
